# 🎱 BILLIARDS ARENA

방 코드 하나로 친구와 진짜 온라인 당구를 즐기는 웹 게임입니다. 설치·회원가입 없이 브라우저에서 바로 플레이하세요.

**▶ 플레이: https://cavinty1216.github.io/billiards-arena/**

## 게임 모드

| 모드 | 인원 | 규칙 |
| --- | --- | --- |
| 사구(4구) | 1:1 | 한국식 4구 — 두 빨간 공을 모두 맞히면 1점, 쿠션 먼저 맞히고 하면 2점, 7점 승리 |
| 포켓 8볼 | 1:1 | 솔리드/스트라이프 그룹을 정하고 마지막에 8번 공 (샷 콜 생략한 단순화 버전) |
| 8볼 스코어전 | 3~4인 개인전 | ★이 앱의 변형 규칙★ 각자 개인전으로 공 1개=1점·8번=3점, 9점 승리. 정식 8볼은 2인 게임이라 3~4인 규칙이 따로 존재하지 않아 별도 점수전으로 만들었습니다 |
| 튜토리얼 | 혼자 | 사구 7단계 · 8볼 7단계, 직접 쳐보며 배우기 |

## 사용법

1. **방 만들기** → 5자리 방 코드 생성
2. 친구는 같은 페이지에서 **방 코드 입력 후 입장**
3. 방장이 **게임 시작**

방 코드를 모르는 사람은 방에 들어올 수 없지만, 암호나 인증 수단은 아니니 친구들과만 공유하세요.

## 기술

- 순수 HTML/CSS/JS, 프레임워크·빌드 도구 없음
- 물리 엔진: 자체 구현 (고정 스텝 시뮬레이션, 공-공/공-쿠션 반사, 스핀)
- 온라인 동기화: 공개 MQTT over WebSocket 릴레이 (계정·결제 불필요, 무료)
  - 방 코드가 있어야 방 참여 가능, 방장 클라이언트가 권위자(authoritative)로 게임 상태 결정 → 다른 사람 차례 조작 불가
  - 공개 테스트 서버를 사용하므로 안정성 보장이 없고, 닉네임에 실명·개인정보를 쓰지 마세요
- 호스팅: GitHub Pages (무료)

## 실행

정적 파일이므로 `index.html`을 그대로 서빙하면 됩니다. 단독 실행 파일은 `billiards-arena-standalone.html` 하나로도 동작합니다.
